# Assignment 3 – Machine Learning

Proyecto desarrollado en Jupyter Notebook.

## Estructura

```
notebooks/   Notebooks de Jupyter (el trabajo principal)
data/raw/    Datos originales (no se suben a git)
data/processed/  Datos procesados (no se suben a git)
src/         Funciones de apoyo reutilizables
```

## Puesta en marcha

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab                      # o abre los .ipynb en VS Code
```
